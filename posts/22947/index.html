Synology: NAT Traversal with an frp Server

Created2023-06-10|Updated2024-10-07
|Word Count:1.9k|Reading Time:10mins|Comments:

继上一篇配置群晖教程【Sysnology】配置群晖DS3615xs

如果你也成功装一台NAS的话 首先祝贺你 打开了NAS这个新世界
那么接下来 跟着我一起利用frp技术 实现远程访问NAS

开始

配置服务端

wget远程下载frp压缩包
wget https://github.com/fatedier/frp/releases/download/v0.36.0/frp_0.36.0_linux_amd64.tar.gz

压缩tar -zxvf

删除多余的压缩包rm -rf

进入frp文件夹cd 删除多余的文件夹

配置frps.ini

启动frps./frps -c ./frps.ini

打开群晖的ssh


然后打开命令提示符


wget远程下载frp压缩包(版本0.36.0)
wget https://github.com/fatedier/frp/releases/download/v0.36.0/frp_0.36.0_linux_amd64.tar.gz

在用户根目录ls查看文件ls

解压压缩包tar -zxvf

删除多余的文件/压缩包rm -rf

进入frp文件夹cd

现在在配置的是客户端 client 所以删去不要的服务端（server）

配置frpc.inivi frpc.ini
frpc.ini初始配置

配置frpc的http_webdav


下载WebDAV Server套件 进入套件中心


ds_file

http

启动frpc.ini ./frpc -c ./frpc.ini

ps:结束frp进程

但是据测试 隔一段时间就断开了 再连接 得重启frpc客户端

这是成功的frps.ini配置

隔段时间断开的解决方案：设置心跳时间
frps.ini
heartbeat_timeout = 90//心跳值，负数禁用，不建议改动

frpc.ini
heartbeat_interval = 30//间隔时间
heartbeat_timeout = 90//超时时间
